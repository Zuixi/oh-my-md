# i18n 双语种运行时切换 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 oh-my-md 引入 zh-CN + en 双语种运行时切换（不重启），覆盖 webview UI、原生菜单、用户可见错误文案，零新增运行时依赖。

**Architecture:** 自研 `t()` 外部 store + `useSyncExternalStore` hook（无顶层 Provider）；Rust `menu.rs` 自持两张字符串映射 + 托管 `MenuState`，`set_menu_locale` 命令重建菜单；引擎 broken-image 改走函数注入 Facet（失败时读 live locale，不重建 view）。语种持久化复用现有 `UserSettings`。

**Tech Stack:** React 19 `useSyncExternalStore`、CodeMirror 6 Facet、Tauri 2 managed state + `set_menu`、Vitest + happy-dom + `@testing-library/react`、`cargo test`。

**Spec:** `docs/superpowers/specs/2026-08-16-17-i18n-design.md`

## Global Constraints

- 零新增运行时依赖（不引入 i18next / react-intl / FormatJS）。
- 语种固定 2 个：`Locale = "en" | "zh"`；存储值 `StoredLocale = "auto" | Locale`，默认 `"auto"`。
- `t(key, params?)` 缺失 key 返回 `key` 本身 + dev `console.warn`，**绝不抛**；`{name}` 插值；无 ICU/复数。
- key 扁平、点号分域（`menu.file.new` 等），`Record<string,string>`。
- 引擎不得导入 React / Tauri / locale 模块；broken-image 走函数注入 Facet。
- IPC 单字段 `locale`，无多词字段；Rust `match` 未知 locale → `"en"`，不 panic。
- `set_menu_locale` 重建失败仅 `console.warn`，不抛、不阻塞 webview。
- 运行在 worktree `/Users/wqz/Developer/my_tools/oh-my-md/.worktrees/i18n`（分支 `i18n`）；所有路径相对仓库根。
- 验证命令：引擎 `pnpm test`；桌面 `pnpm --filter @omd/desktop test` 与 `pnpm --filter @omd/desktop build`；Rust `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`；release 前门槛 `pnpm verify`。
- commit 消息遵循 `<type>: <why>`（feat/fix/refactor/docs/test/chore/perf）；本计划写出建议 commit 边界但**不自动执行 commit**（由执行者逐 Task 提交）。

```ts
import { Facet } from "@codemirror/state"
import { WidgetType } from "@codemirror/view"

export const imageResolver = Facet.define<(src: string) => string, (src: string) => string>({
  combine: values => values[values.length - 1] ?? ((s: string) => s),
})

const defaultBroken = (src: string) => `🖼 ${src}（加载失败）`

export const imageBrokenLabel = Facet.define<(src: string) => string, (src: string) => string>({
  combine: values => values[values.length - 1] ?? defaultBroken,
})

export class ImageWidget extends WidgetType {
  constructor(readonly src: string, readonly alt: string, readonly resolvedSrc: string) { super() }
  eq(other: ImageWidget) {
    return this.src === other.src &&
      this.alt === other.alt &&
      this.resolvedSrc === other.resolvedSrc
  }
  toDOM(view: EditorView) {
    const img = document.createElement("img")
    img.src = this.resolvedSrc
    img.alt = this.alt
    img.className = "omd-image"
    img.onerror = () => {
      const label = view.state.facet(imageBrokenLabel)(this.src)
      img.replaceWith(Object.assign(document.createElement("span"), {
        className: "omd-image-broken", textContent: label,
      }))
    }
    return img
  }
}
```

> 注意 `toDOM` 签名由 `toDOM()` 改为 `toDOM(view: EditorView)`；导入 `EditorView`。

- [ ] **Step 4: 实现 store**

`apps/desktop/src/i18n/index.ts`：

```ts
import { useSyncExternalStore, useMemo } from "react"
import { en } from "./messages/en"
import { zh } from "./messages/zh"

export type Locale = "en" | "zh"
export type StoredLocale = "auto" | Locale

const messages: Record<Locale, Record<string, string>> = { en, zh }

export type MenuLocaleSetter = (locale: Locale) => void | Promise<void>

let current: Locale = "en"
let listeners = new Set<() => void>()
let menuSetter: MenuLocaleSetter = () => {}

export function resolveLocale(stored: StoredLocale): Locale {
  if (stored === "en" || stored === "zh") return stored
  const nav = (typeof navigator !== "undefined" && navigator.language) || "en"
  return nav.toLowerCase().startsWith("zh") ? "zh" : "en"
}

function emit(): void {
  for (const fn of listeners) fn()
}

export function getLocale(): Locale {
  return current
}

export function subscribe(fn: () => void): () => void {
  listeners.add(fn)
  return () => { listeners.delete(fn) }
}

export function initLocale(stored: StoredLocale, setMenuLocale?: MenuLocaleSetter): Locale {
  if (setMenuLocale) menuSetter = setMenuLocale
  current = resolveLocale(stored)
  void notifyMenu()
  return current
}

export function setLocale(stored: StoredLocale): Locale {
  current = resolveLocale(stored)
  emit()
  void notifyMenu()
  return current
}

function notifyMenu(): Promise<void> {
  return Promise.resolve(menuSetter(current)).catch(e => {
    // ponytail: 菜单重建失败非文档正确性路径，不阻塞 webview
    console.warn("[i18n] set_menu_locale failed", e)
  })
}

function interpolate(template: string, params?: Record<string, string | number>): string {
  if (!params) return template
  return template.replace(/\{(\w+)\}/g, (_, k: string) =>
    params[k] !== undefined ? String(params[k]) : `{${k}}`)
}

export function t(key: string, params?: Record<string, string | number>): string {
  const table = messages[current]
  const template = table[key]
  if (template === undefined) {
    if (import.meta.env?.DEV) console.warn(`[i18n] missing key: ${key}`)
    return key
  }
  return interpolate(template, params)
}

function useT(): (key: string, params?: Record<string, string | number>) => string {
  const locale = useSyncExternalStore(subscribe, getLocale, getLocale)
  return useMemo(() => {
    const table = messages[locale]
    return (key: string, params?: Record<string, string | number>) => {
      const template = table[key]
      if (template === undefined) {
        if (import.meta.env?.DEV) console.warn(`[i18n] missing key: ${key}`)
        return key
      }
      return interpolate(template, params)
    }
  }, [locale])
}

export { useT }

export const localeOptions: { value: StoredLocale; key: string }[] = [
  { value: "auto", key: "settings.language.auto" },
  { value: "en", key: "settings.language.en" },
  { value: "zh", key: "settings.language.zh" },
]
```

> `useT` 返回的 `t` 闭包绑定 hook 捕获的 `locale`（订阅触发重渲染时刷新），模块级 `t` 读 live `current`（供命令式代码如 confirm 文案用）。二者共享 `interpolate`。

```rust
pub fn install<R: Runtime>(app: &App<R>) -> tauri::Result<()> {
    let state = MenuState::default();
    rebuild_from_state(app.handle(), &state.recents, &state.locale)?;
    app.manage(Mutex::new(state));
    app.on_menu_event(|handle, event| {
        let _ = handle.emit(MENU_EVENT, event.id().as_ref());
    });
    Ok(())
}

pub fn rebuild<R: Runtime>(app: &AppHandle<R>, recents: &[String]) -> tauri::Result<()> {
    // 兼容现有调用：读 managed state 取 locale，或接受默认
    let locale = app
        .try_state::<Mutex<MenuState>>()
        .and_then(|s| s.lock().ok().map(|g| g.locale.clone()))
        .unwrap_or_else(|| "en".to_string());
    rebuild_from_state(app, recents, &locale)
}

pub fn set_recent_files(app: &AppHandle, paths: &[String]) -> tauri::Result<()> {
    if let Some(state) = app.try_state::<Mutex<MenuState>>() {
        let mut g = state.lock().map_err(|e| e.to_string())?;
        g.recents = paths.to_vec();
        let locale = g.locale.clone();
        drop(g);
        return rebuild_from_state(app, paths, &locale);
    }
    rebuild_from_state(app, paths, "en")
}

#[tauri::command]
pub fn set_menu_locale(
    app: AppHandle,
    locale: String,
    state: State<'_, Mutex<MenuState>>,
) -> Result<(), String> {
    {
        let mut g = state.lock().map_err(|e| e.to_string())?;
        g.locale = locale.clone();
    }
    let recents = state.lock().map(|g| g.recents.clone()).map_err(|e| e.to_string())?;
    rebuild_from_state(&app, &recents, &locale)
}
```
