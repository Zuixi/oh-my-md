## Goal

补齐首轮 i18n 遗留的用户可见英文文案，使 zh 语种下原生菜单、冲突横幅、状态横幅、错误提示全部本地化。

## Architecture（业内最佳实践，三条铁律）

1. **key 是唯一数据源，消费点 `t()`。** 模块级常量只存 `key` 字符串，绝不存显示文案、绝不模块级调用 `t()`（否则冻结在加载时语种——这正是 R13 的根因）。
2. **测试断言语义、不钉死文案。** 现有测试硬编码英文（如 `toHaveBeenCalledWith("Recovery write failed: disk full")`），迁移后改为断言 `t("key")` 返回值，使测试语种无关。
3. **Rust 菜单与 TS 命令面板共用一套 zh 词。** format/view 菜单项与 `cmd.label.*` 是同一概念，zh 翻译逐字对齐（加粗/斜体/删除线/…），避免同一概念两套译法。

## Tech Stack

Rust（`menu.rs` 的 `MenuLabels`/`menu_strings`）、React 19 `useT()`/模块级 `t`、Vitest + `cargo test`。

## Global Constraints

- 零新增运行时依赖。
- `t` 缺失 key 返回 key + dev warn，绝不抛；`{name}` 插值。
- 模块级常量只存 key；显示文案一律在消费点 `t()`（React 组件用 `useT()`，非组件模块用模块级 `t`）。
- EN 文案保持 verbatim（现有测试 + 用户习惯）；zh 与 `cmd.label.*` 对齐。
- 提交消息 `<type>: <why>` 无 scope（`commit-msg` hook 拒绝 scope）。
- 验证：`pnpm --filter @omd/desktop test`、`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`、`pnpm verify`。
- 每步 2–5 分钟动作、先测后实现（TDD）。
