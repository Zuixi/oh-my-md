# 键盘快捷键指南

oh-my-md 的快捷键分成两层：**编辑器排版快捷键**（聚焦在编辑区时生效，由引擎的 `markdownKeymap` 提供）和**应用级快捷键**（由窗口/命令面板处理）。所有排版命令同时注册在命令面板（⇧⌘P）里，记不住键位时可以搜命令名。

## 编辑器排版快捷键

在编辑区光标处或选中文本后触发。**可切换（toggle）**：对同一段文本再按一次同键，会去掉标记。

### 行内格式

| 快捷键 | 动作 | 说明 |
|---|---|---|
| ⌘B | 粗体 | 包 `**文本**` |
| ⌘I | 斜体 | 包 `*文本*` |
| ⇧⌘X | 删除线 | 包 `~~文本~~` |
| ⇧⌘\` | 行内代码 | 包 `` `代码` ``；内容里已有反引号时自动改用双反引号 |

- **光标在单词内/词边界**（未选中）：直接作用于光标所在单词。
- **有选区**：作用于选中文本，之后文本保持选中，方便连续排版。
- **再次按同键**：移除标记，还原原文。

例如在 `hello world` 中把光标放进 `world` 后按 ⌘B，得到 `hello **world**`，光标停在两个 `**` 之间可继续输入。

### 标题

| 快捷键 | 动作 |
|---|---|
| ⌘1 – ⌘6 | 设为 1–6 级标题 / 同级别再按取消 |

- 作用于光标所在行；多行选中时逐行添加。
- 已是其他级别标题时改为目标级别（不会叠加 `#`）。
- 例如在 `## 章节` 上按 ⌘1 变成 `# 章节`，再按 ⌘1 回到 `章节`。

### 列表与引用

| 快捷键 | 动作 |
|---|---|
| ⌥⌘7 | 有序列表 |
| ⌥⌘8 | 无序列表 |
| ⌥⌘9 | 引用 |
| Enter（列表项正文） | 续写同类型列表项；空项（只有 marker）退出列表 |
| Tab / Shift-Tab（列表项） | 缩进 / 反缩进 2 个空格；非列表行不拦截 Tab |

- 多行选中时整块生效；已是该列表/引用则整体移除标记。
- 有序列表会自动按 `1. 2. 3.` 编号；紧邻已有有序列表时接着续号。
- 在无序与有序之间切换会替换标记（`- ` ↔ `1. `）。
- 列表续写不开启通用 `indentOnInput`；引用内的列表续行保留当前引用前缀。

### 代码块与链接

| 快捷键 | 动作 |
|---|---|
| ⇧⌘K | 代码块：给选区（或光标所在段落）包上 ``` 围栏；已是代码块则去掉围栏 |
| ⌘K | 插入链接 |

插入链接的行为：

- **选中了 URL**（以 `http://` / `https://` / `www.` 开头）：生成 `[url](url)`，URL 部分保持选中，可直接改写显示文字。
- **选中普通文本**：生成 `[文本](` 并把光标停在括号里，输入目标地址即可。
- **光标在单词上**：以该单词作为链接文字，光标停在括号里。

## 应用级快捷键

| 快捷键 | 动作 |
|---|---|
| ⇧⌘P | 命令面板（所有功能的统一入口） |
| ⌘F | 当前文档查找 |
| ⌘H | 当前文档查找并展开替换 |
| ⌘G / Enter（查找框） | 下一个匹配 |
| ⇧⌘G / ⇧Enter（查找框） | 上一个匹配 |
| Escape（查找打开时） | 关闭查找并焦点回编辑器 |
| ⇧⌘F | 文件夹搜索 |
| ⌘O | 打开文件 |
| ⌘N | 新建标签 |
| ⌘W | 关闭标签 |
| ⌘S / ⇧⌘S | 保存 / 另存为 |
| ⇧⌘O | 折叠 / 展开大纲 |
| ⌘E | 切换 live / source 模式 |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |

> 注意：⌘K 在编辑区里是「插入链接」，不是命令面板（命令面板已移到 ⇧⌘P）。
>
> ⌘F 是文档内查找，不是文件夹搜索。文件夹搜索用 ⇧⌘F，或命令面板里的 Search in folder。
>
> 拼写检查不是快捷键：Settings 里的 Spellcheck 会把编辑器 `.cm-content` 设为 `spellcheck="true"` / `"false"`，用 WebView 原生拼写。

## 使用技巧

- 排版快捷键在 **live 与 source 两种模式**下行为一致，都直接编辑 Markdown 源码。
- 忘记键位时：按 ⇧⌘P 搜索 `Bold`、`Heading 2`、`Ordered list` 等命令名即可执行并看到对应快捷键。
- 想快速把一段话变成标题：选中多行 → ⌘2；再按 ⌘2 取消。
- 连续排版：先选中文字 ⌘B 加粗，光标仍在选区内，接着按 ⌘I 再加斜体，得到 `***文本***`。
