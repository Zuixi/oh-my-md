# 键盘快捷键指南

oh-my-md 的快捷键分成两层：**编辑器排版快捷键**（聚焦在编辑区时生效，由引擎的 `markdownKeymap` 提供）和**应用级快捷键**（由窗口/命令面板处理）。所有排版命令同时注册在命令面板（⇧⌘P）里，记不住键位时可以搜命令名。

> 平台说明：快捷键以 ⌘/⌥ 表示主修饰键；Windows/Linux 上 ⌘→Ctrl、⌥→Alt，其余不变（引擎以 `Mod-` 匹配，自动映射）。

## 编辑器排版快捷键

在编辑区光标处或选中文本后触发。所有命令都是**语义切换（toggle）**：重复按同键会在“目标格式”和“原文”之间切换，不会继续叠加标记。一次成功排版只产生一个事务、一个撤销步；它不会和相邻输入或上一次排版合并。

当前语法位置无法安全改写时（例如行内选区跨越代码/公式/段落或只覆盖半个语法节点；块级命令落在表格内部），命令会保持文档不变。这是刻意 fail-closed，不会插入半个标记或产生不可逆结果；解析尚未覆盖光标时也会暂时 no-op，而不是强制解析全文。标题、列表、引用这些块级命令遇到混合选区时会先统一到目标状态（补齐未格式化的行），而不是逐行反转。

### 行内格式

| 快捷键 | 动作 | 说明 |
|---|---|---|
| ⌘B | 粗体 | 包 `**文本**` |
| ⌘I | 斜体 | 包 `*文本*` |
| ⌘U | 下划线 | 包 `<u>文本</u>` |
| ⇧⌘X | 删除线 | 包 `~~文本~~` |
| ⌘\` | 行内代码 | 包 `` `代码` ``；内容里已有反引号时自动使用比最长反引号串更长一档的围栏；⇧⌘\` 是兼容备用键 |

- **光标在单词内/词边界**（未选中）：直接作用于光标所在单词。
- **有选区**：作用于选中文本，之后文本保持选中，方便连续排版。
- **再次按同键**：移除同一语义层级的标记，还原原文；嵌套强调只移除本次命令对应的层级（例如在 `***文本***` 上切粗体得到 `*文本*`）。
- **异类格式可组合**：在一个已完整解析的行内节点上添加另一种非代码格式时，新标记包住整个节点；例如 `` `代码` `` 再按 ⌘B 得到 `` **`代码`** ``，不会把 `**` 插进代码内容。

例如在 `hello world` 中把光标放进 `world` 后按 ⌘B，得到 `hello **world**`，光标停在两个 `**` 之间可继续输入。

### 标题

| 快捷键 | 动作 |
|---|---|
| ⌘1 – ⌘6 | 设为 1–6 级标题 / 同级别再按取消 |

- 作用于光标所在行；多行选中时逐行添加。
- 已是其他级别标题时改为目标级别（不会叠加 `#`）。
- 例如在 `## 章节` 上按 ⌘1 变成 `# 章节`，再按 ⌘1 回到 `章节`。

### 列表与引用

| 快捷键 | 动作 |
|---|---|
| ⌥⌘7 | 有序列表 |
| ⌥⌘8 | 无序列表 |
| ⌥⌘9 | 引用 |
| Enter（列表项正文） | 续写同类型列表项；空的嵌套项退出一层，空的顶层项退出列表 |
| Tab / Shift-Tab（列表项） | 按 CommonMark 容器层级缩进 / 反缩进；非列表行不拦截 Tab |

- 多行选中时整块生效；已是该列表/引用则整体移除标记。
- 有序列表会自动按 `1. 2. 3.` 编号；紧邻已有有序列表时接着续号。
- 在无序与有序之间切换会替换标记（`- ` ↔ `1. `）。
- 混合选区会整体规范化为目标类型；重复执行同一命令不会叠加多层列表或引用标记。
- 列表续写不开启通用 `indentOnInput`；引用内的列表续行保留当前引用前缀。

### 代码块与链接

| 快捷键 | 动作 |
|---|---|
| ⇧⌘K | 代码块：给选区（或光标所在段落）包上 ``` 围栏；光标在代码块内或选中整个代码块则去掉围栏 |
| ⌘K | 插入链接 |

代码块命令只在能保证可逆的顶层上下文里执行。引用、列表、缩进代码、公式块、前导元数据和表格内部会 no-op，而不是生成无法再次切换的嵌套围栏。

插入链接的行为：

- **选中了 URL**（以 `http://` / `https://` / `www.` 开头）：生成 `[url](url)`，URL 部分保持选中，可直接改写显示文字。
- **选中普通文本**：生成 `[文本](` 并把光标停在括号里，输入目标地址即可。
- **光标在单词上**：以该单词作为链接文字，光标停在括号里。
- **光标在已有链接内**：选中该链接的 URL；再次按 ⌘K 不会重复包裹。
- **完整选中已有链接**：还原为链接文字（unlink）；只选中链接的一部分则 no-op，避免产生含义不明的半链接。
- **光标在裸 URL 内**：扩展到整个 URL 后只包裹一次；部分选中裸 URL 则 no-op。

## 应用级快捷键

| 快捷键 | 动作 |
|---|---|
| ⇧⌘P | 命令面板（所有功能的统一入口） |
| ⌘P | 快速打开文件 |
| ⌘, | 打开设置 |
| ⌘\ | 折叠 / 展开侧边栏 |
| ⌘F | 当前文档查找 |
| ⌘H | 当前文档查找并展开替换 |
| ⌘G / Enter（查找框） | 下一个匹配 |
| ⇧⌘G / ⇧Enter（查找框） | 上一个匹配 |
| Escape（查找打开时） | 关闭查找并焦点回编辑器 |
| ⇧⌘F | 文件夹搜索 |
| ⌘O | 打开文件 |
| ⌘N | 新建标签 |
| ⇧⌘N | 新建窗口 |
| ⌘V | 智能粘贴（HTML 语义转换；代码/数学区域自动使用纯文本） |
| ⇧⌘V | 粘贴为纯文本 |
| ⌘W | 关闭标签 |
| ⌘S / ⇧⌘S | 保存 / 另存为 |
| ⇧⌘O | 折叠 / 展开大纲 |
| ⌘E | 切换 live / source 模式 |
| ⌘Z / ⇧⌘Z | 撤销 / 重做 |

> 注意：⌘K 在编辑区里是「插入链接」，不是命令面板（命令面板已移到 ⇧⌘P）。
>
> ⌘F 是文档内查找，不是文件夹搜索。文件夹搜索用 ⇧⌘F，或命令面板里的 Search in folder。
>
> 拼写检查不是快捷键：Settings 里的 Spellcheck 会把编辑器 `.cm-content` 设为 `spellcheck="true"` / `"false"`，用 WebView 原生拼写。

## 使用技巧

- 排版快捷键在 **live 与 source 两种模式**下行为一致，都直接编辑 Markdown 源码。
- 每次成功排版都是一个独立撤销步：先输入文字再按 ⌘B，第一次 ⌘Z 只撤销加粗，第二次才撤销输入；连续按 ⌘B、⌘I 也各自可撤销。
- 忘记键位时：按 ⇧⌘P 搜索 `Bold`、`Heading 2`、`Ordered list` 等命令名即可执行并看到对应快捷键。
- 想快速把一段话变成标题：选中多行 → ⌘2；再按 ⌘2 取消。
- 连续排版：先选中文字 ⌘B 加粗，光标仍在选区内，接着按 ⌘I 再加斜体，得到 `***文本***`。
